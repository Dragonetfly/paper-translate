# 专业翻译审核

先通读论文确定材料、器件、实验方法与指标的实际含义，再建立本篇术语表。相同概念固定译法；首次写出全称和缩写，后续保留缩写。专业缩写以原文定义为准，不能凭熟悉程度补全。

本次已验证论文中的可选起始词表，**仅在领域和语义匹配时使用**：

| English | 中文 |
|---|---|
| micro light-emitting diode (micro-LED) | 微型发光二极管 |
| perovskite micro-LED (micro-PeLED) | 钙钛矿微型发光二极管 |
| mass transfer (micro-LED fabrication) | 巨量转移 |
| photoluminescence (PL) | 光致发光 |
| electroluminescence (EL) | 电致发光 |
| external quantum efficiency (EQE) | 外量子效率 |
| photoluminescence quantum yield (PLQY) | 光致发光量子产率 |
| light extraction efficiency (LEE) | 光提取效率 |
| full width at half maximum (FWHM) | 半峰全宽 |
| radiance | 辐亮度 |
| radiative recombination ratio | 辐射复合比例 |
| finite-difference time-domain (FDTD) | 时域有限差分 |

逐段检查：

1. 原文全部信息都在译文中：实验顺序、温度、时间、转速、浓度、层厚、沉积速率、像素尺寸、数值范围和样本数。
2. `radiance` 不能译为光度学“亮度”；`yield`、`efficiency`、辐射复合比例及内/外量子效率不混用。
3. 区分“尺寸减小导致指标降低”与“指标随尺寸增大降低”，保留因果强弱及 may / suggest / mainly 等限定。
4. 数字检查器只能比较数字，不能识别单位、正负号、数值对应关系和式子含义。另核查 μ/µ、mA/A、nm/μm、上/下标、百分号、角标和量纲。
5. 图注保持 a/b/c 等子图对应和比例尺。图中数据、公式及参考文献不翻译、不重画、不让白框遮挡。
6. PDF 的断行连字符与连字先恢复完整词；列间、跨页续句保持连贯。提取不确定时看原页，不能猜内容。
7. 用句段级覆盖表核对，摘要、方法、资助、声明和长图注不能被当作可省略内容。重复页眉、授权和版权声明可以按实际请求保留，并记录理由。

对无法确认的专业术语，先用文中定义及图表判定；仍有歧义时查可靠专业来源并在笔记记录，不让猜测进入定稿。
